# 部署前必读 · 已知问题与限制

这份代码是"能跑通"的工程实现,直接部署往往能用,但有几个**部署前提与注意事项**需要先了解。

## 1. 出站请求可能被源站 WAF 拦截(最常见)

源站前置了 WAF,会按 **IP 信誉**判定:机房/数据中心 IP 容易被要求人机验证(该验证为云端风控 + 设备指纹,难以自动通过),住宅宽带 IP 则通常直接放行。

因此,若部署在云服务器上,建议让**出站请求**经过一个"干净"的出口(家庭宽带 / 住宅代理),即设置:

```bash
VCY_SOCKS=socks5h://127.0.0.1:1080
```

留空则直连;代理探测失败会自动回退直连。

## 2. 自动登录(占位,未包含求解)

源站登录验证码曾为"天爱 POW"(可离线求解),现已升级为**图片拼图滑块**,且判定在服务端。本公开版**未包含**该求解器,因此 `/api/auth/login` 占位返回失败。

浏览类功能不依赖自动登录(用源站匿名态即可)。若需要登录态,请自行实现验证码求解,或改用其它方式提供 token。

## 3. 登录态 token 可能被撤销

源站同一账号在新设备登录会**顶掉**旧会话,导致服务端缓存的 `refresh_token` 失效。失效后,依赖登录态的接口(如视频完整版)会返回 401。此时需要重新获取新 token 写入 `config.json` 并重启服务。

## 4. 视频编码兼容性

源站部分视频为 **H.265 / HEVC** 编码,部分浏览器(尤其 Chrome / Android)无法解码。建议使用 **Edge 或 Safari** 观看;前端已对不支持的浏览器给出提示。

## 5. 图片防盗链

源站图片有 Referer 校验,前端已加:

```html
<meta name="referrer" content="no-referrer">
```

更换域名部署时请保留该设置。

## 6. 使用与传播

代理站会消耗源站资源。请**自用、低频**,避免公开传播,以免源站封 IP 或加验证。
